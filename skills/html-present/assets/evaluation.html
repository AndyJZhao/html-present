READ THIS FIRST · 02

先区分排名、概率与决策

AUROC / AUPRC
衡量目标类的排序。AUPRC 使用 average precision；随机基线分别为 0.5 和当前阳性比例。
Own decision
模型的多分类 argmax 是否落在目标组中，不等于“目标风险 ≥ 0.5”。
操作点
测试集固定特异度／敏感度用于探索；验证集预定阈值用于检查固定规则的测试表现。
95% CI
固定已训练模型，按真实类别分层、对样本配对 bootstrap。不包括重新训练或随机种子的变异。
容量与净收益
容量：只能检查最高风险的一部分样本时捕获多少目标。净收益：给误报分配成本后的效用；此处仅是教学场景。
图像条件
噪声／模糊是对相同测试 ID 的合成压力测试，不是独立采集的新数据域。
